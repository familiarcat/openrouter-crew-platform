## 🚀 How to Execute

### Quick Start (Copy & Paste)
```bash
# 1. Create project
mkdir -p domains/test-projects/baritalia-stl
cd domains/test-projects/baritalia-stl

# 2. Initialize
pnpm init
mkdir -p agents/{research-agent,website-agent,business-plan-agent,finance-agent,gateway}
mkdir -p website/src/{app,components}
mkdir -p outputs

# 3. Set environment
export OPENROUTER_API_KEY="sk-or-..."
export CREW_API_URL="http://localhost:8000"

# 4. Run
pnpm run generate:business

# 5. View outputs
ls outputs/
# business-plan.md
# financial-model.json
# cost-tracking.json
```

### Detailed Timeline
Follow **TEST_PROJECT_ROADMAP.md** for hour-by-hour breakdown:
