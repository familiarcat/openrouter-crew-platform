# OpenRouter Crew VSCode Extension

Professional AI-powered code assistant that rivals Cursor and GitHub Copilot while being 90% cheaper.

## Features

- **Cost Optimization**: Routes prompts to the most cost-effective model (Gemini vs Claude vs GPT-4).
- **Intent Detection**: Understands if you are asking for code, explanation, or refactoring.
- **Budget Management**: Tracks spending and enforces budgets.
- **Privacy**: Direct calls to OpenRouter, no intermediate data harvesting.

## Setup

1. Run `pnpm install` in the root.
2. Open this folder in VSCode.
3. Press F5 to launch the extension in debug mode.
