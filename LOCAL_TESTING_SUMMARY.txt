Q1: What pnpm script for entire system testing?
────────────────────────────────────────────────

MAIN COMMAND:
  pnpm dev:universal

DOES:
  • Cleans up stuck ports automatically
  • Starts all 4 Next.js dashboards on ports 3000, 3002, 3003, 3004
  • Starts Supabase local database on port 54321
  • Watches VSCode extension for changes
  • Waits for services to come online
  • Opens browser with all 4 dashboards in separate tabs
  • Provides real-time output showing service status

EXAMPLE OUTPUT:
  ⏳ Waiting for dashboards to come online...
  ✅ Ready: http://localhost:3000 (Unified Dashboard)
  ✅ Ready: http://localhost:3002 (DJ Booking)
  ✅ Ready: http://localhost:3003 (Alex AI)
  ✅ Ready: http://localhost:3004 (Product Factory)
  
  Browser opens with all 4 tabs automatically loaded

ALTERNATIVE COMMANDS (if you don't want some components):
  pnpm dev:dashboards        - Just web servers, no Supabase
  pnpm dev:unified           - Just unified dashboard (PM system)
  pnpm supabase:start        - Just database
  pnpm dev:all               - Using docker-compose


Q2: Describe installation steps for VSCode extension
─────────────────────────────────────────────────────

INSTALLATION:
  
  Step 1: Build and install
    pnpm vscode:install
  
  Step 2: Reload VSCode
    • Press: Cmd+Shift+P (Mac) or Ctrl+Shift+P (Windows/Linux)
    • Type: "Developer: Reload Window"
    • Press: Enter
    • Wait: 2-3 seconds for reload

  Step 3: Verify installation
    • Look for new icon in left activity bar (sidebar)
    • It shows a small icon next to Files, Search, Git
    • Click the icon to expand the panel

FEATURES AVAILABLE:
  • Projects panel - Quick navigation to all projects
  • Crew roster - View all available agents and their status
  • Cost meter - Real-time daily budget tracking
  • Memory browser - Search and view past conversations
  • Commands - Palette of AI-powered commands

DEVELOPMENT MODE (if modifying extension):
  • Keep terminal running: pnpm --filter openrouter-crew-vscode watch
  • Make changes to extension code
  • In VSCode: Cmd+Shift+P → "Developer: Reload Window"
  • Changes appear immediately


Q3: CLI usage guide
────────────────────

BUILD THE CLI:
  pnpm --filter @openrouter-crew/cli build

AVAILABLE COMMANDS:
  crew --help                           # Show all commands
  
  Cost Management:
    crew cost status                    # Current daily spending
    crew cost forecast --days 30        # 30-day projection
    crew budget get                     # Current budget limit
    crew budget set --limit 100         # Set daily limit ($100)

  Project Management:
    crew project list                   # List all projects
    crew project create --name "foo"    # Create new project
    crew project info <id>              # Project details

  Crew Management:
    crew crew list                      # All available agents
    crew crew status                    # Current assignments
    crew crew assign <member> <task>    # Assign work

  Analytics:
    crew analytics summary              # Budget overview
    crew analytics detailed             # Detailed metrics
    crew analytics export               # CSV export

  Memory System:
    crew memory list                    # All memories
    crew memory search "keyword"        # Find memories
    crew memory show <id>               # View specific memory
    crew memory delete <id>             # Remove memory

  History & Audit:
    crew history list                   # Recent operations
    crew history show <operation-id>    # Operation details
    crew history export                 # Export history

COMMON WORKFLOWS:
  # Check if you're within budget today
  crew cost status
  
  # See who's available to work
  crew crew list
  
  # Find information about previous work
  crew memory search "sprint planning"
  
  # Check all your projects
  crew project list
  
  # Get budget status
  crew budget get

Problem: "Port 3000 already in use"
Solution: bash scripts/system/cleanup-ports.sh

Problem: "Supabase won't start"
Solution: Make sure Docker is running
         pnpm supabase:stop && pnpm supabase:start

Problem: "VSCode extension not showing"
Solution: Reload VSCode (Cmd+Shift+P → "Developer: Reload Window")

Problem: "Dashboard won't load"
Solution: Check logs: tail -f .logs/web-portal.log

Problem: "OpenRouter API not responding"
Solution: Add OPENROUTER_API_KEY to .env.local
         Restart: pnpm dev:unified

Problem: "Terminal stuck after Ctrl+C"
Solution: ps aux | grep node
         kill -9 <PID>
